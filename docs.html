Calibrated Confidence Scoring Defined

Unlike uncalibrated raw heuristic scores, Sentinel's confidence metric represents the empirical posterior probability that the classification is correct. This enables mathematically sound policy thresholds:

0.99 Confidence Deterministic

Direct ASN registry matches, authoritative Tor exit directory relays, datacenter server subnets, or verified clean residential broadband. Immediate hard-kick is statistically safe (>99.9% precision).

0.95 Confidence Carrier Classified

Mobile cellular networks with dynamic CGNAT pooling, or recognized gaming route accelerators (e.g. ExitLag). Requires whitelist preservation for legitimate gamers.

0.88 Confidence Behavioral Anomaly

Dynamic Tunnel & Gateway Behavioral Anomaly Detection on residential IP space. Graduated Defense recommended: soft-alert, challenge (2FA/CAPTCHA), or audit log rather than instant hard kick.

Field Dictionary

Field Type Description

threat_type string Primary classification (e.g. Commercial VPN, Datacenter VPS, Residential Proxy, Tor Exit Node, Clean Residential).
is_vpn boolean Convenience boolean flag set to true if the connection represents an anonymizing proxy, VPN, or datacenter hop.
is_gaming_optimizer boolean True if traffic originates from a legitimate gaming network accelerator (e.g., ExitLag, WTFast, NoPing). Never blocked if whitelist is active.

provider string Carrier or ISP organization name associated with the Autonomous System.
hostname string (nullable) Reverse DNS (PTR) hostname sanitized with internal octet masking for privacy.

REST Endpoints

5. Endpoints Specification

POST /v1/check Recommended for Zero-Log Hygiene

Evaluates an explicit target IP address transmitted via a JSON request body ({ "ip": "1.1.1.1" }). Privacy Advantage: Sending the IP in the POST body ensures visitor IPs are never recorded in URL access logs, intermediate proxy access logs, or browser histories, preserving Sentinel's Zero-Log Volatile Memory Architecture.

Request Body (application/json):
{ "ip": "185.213.154.20" }
GET /v1/check?ip={target_ip}

Evaluates an explicit target IPv4 or IPv6 address passed as a URL query parameter. Supported across all client libraries and legacy game server connectors.

Parameters:

GET /v1/check

Automatically detects and evaluates the inbound caller's connection from edge proxy headers (CF-Connecting-IP, X-Forwarded-For).

Global Anycast edge liveness probe. Returns HTTP 200 OK ({"status": "ok"}). No authentication required.

Resilience Pattern

8. Production Fail-Open Architecture

Security software should never create single points of failure. In production web applications and APIs, always wrap Sentinel calls in a fail-open handler: if network connectivity to the edge fails or times out, permit the connection and log a warning rather than locking out legitimate visitors.

javascript — Node / Express Fail-Open Middleware 
// Configure Express trusted proxies to safely resolve req.ip:
app.set("trust proxy", "loopback, linklocal, uniquelocal");

async function sentinelGuard(req, res, next) {
  // Use securely validated client IP (prevents header spoofing attacks)
  const clientIP = req.ip || req.socket.remoteAddress;

  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 1200); // 1.2s timeout

    // Transmit via POST JSON body for heightened zero-log URL privacy
    const resp = await fetch("https://api.antivpn.tech/v1/check", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${process.env.SENTINEL_API_KEY}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify({ ip: clientIP }),
      signal: controller.signal
    });
    clearTimeout(timeout);

    // Fail-open: Permit traffic on non-200 edge error or temporary rate limits
    if (!resp.ok) return next();

    const verdict = await resp.json();
    if (verdict.action === "BLOCK" && verdict.confidence >= 0.95) {
      return res.status(403).json({ error: "Access Denied: Untrusted Ingress Hop" });
    }

    next();
  } catch (err) {
    // Fail-open: Never disrupt legitimate user traffic if edge network is unreachable
    console.warn(`[Sentinel Warning] Fail-open bypass for ${clientIP}: ${err.message}`);
    next();
  }
}
Reverse Proxy Security Warning: Never trust req.headers["cf-connecting-ip"] directly on servers open to the public web unless locked to Cloudflare's published IP ranges (via firewall rules or Authenticated Origin Pulls). On direct connections, attackers can spoof this header with clean residential IPs. Always rely on validated framework proxy settings (app.set('trust proxy', ...)).
Implementation Pattern

9. Graduated Defense Policy Recipe

Take full advantage of confidence and reason_codes to separate deterministic datacenter/VPN drops from residential proxies:

javascript — Multi-Tier Graduated Enforcement 
function enforceIngressPolicy(verdict) {
  // 1. Deterministic Hard Drop (Commercial VPNs, Hosting Scrapers, Tor)
  if (verdict.risk_score >= 85 && verdict.confidence >= 0.95) {
    return { decision: "DENY", status: 403 };
  }

  // 2. Probabilistic Step-Up Challenge (Residential Proxies & Tunnels)
  if (verdict.reason_codes.includes("RESIDENTIAL_TUNNEL_PROXY")) {
    return { decision: "CHALLENGE", action: "PROMPT_CAPTCHA_OR_MFA" };
  }

  // 3. Clean Connection: Allow without friction
  return { decision: "PASS" };
}
