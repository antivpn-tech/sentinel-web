Payload Specification

3. Output Schema & Confidence Scoring

Sentinel provides nuanced, multi-dimensional outputs. Instead of forcing your application into a rigid binary decision, responses include both an integer risk_score (0–100) and a normalized confidence float (0.00–1.00), paired with machine-readable reason_codes.

JSON — Edge Verdict Payload 
{
  "ip": "185.213.154.20",
  "action": "BLOCK",
  "risk_score": 95,
  "confidence": 0.98,
  "threat_type": "Commercial VPN",
  "reason_codes": [
    "CARRIER_COMMERCIAL_VPN",
    "HOSTING_INFRASTRUCTURE_MATCH",
    "GATEWAY_EXIT_ACTIVE"
  ],
  "asn": 206016,
  "provider": "Mullvad VPN",
  "carrier_type": "transit_cloud",
  "country": "SE",
  "city": "Stockholm",
  "execution_time_ms": 0.38,
  "dataset_sync_timestamp": "2026-10-09T03:55:00Z"
}

Field Dictionary

Field Type Description
ip string The evaluated IPv4 or IPv6 address.
action string ALLOW or BLOCK based on standard baseline thresholds.
risk_score integer (0–100) Assessed threat severity. 0 = clean subscriber, 100 = active confirmed threat hop.
confidence float (0.00–1.00) Statistical certainty of the classification. Allows developers to tune sensitivity.
threat_type string Primary classification (e.g. Commercial VPN, Datacenter VPS, Residential Proxy, Tor Exit Node, Clean Residential).
reason_codes array[string] Standardized machine-readable triggers for programmatic rule matching.
execution_time_ms float Local in-memory isolate compute duration in milliseconds.
dataset_sync_timestamp ISO 8601 string Timestamp when the active Global Threat Grid delta was synchronized into isolate memory.

REST Endpoints

5. Endpoints Specification

GET /v1/check?ip={target_ip}

Evaluates an explicit target IPv4 or IPv6 address. Standard dual-stack ingress lookup.

Parameters:
  • ip (string, required): Explicit IPv4 or IPv6 string.
GET /v1/check

Automatically detects and evaluates the inbound caller's connection from edge proxy headers (CF-Connecting-IP, X-Forwarded-For).

GET /v1/license/status

Returns the authenticated license key's current tier, monthly allotment, and remaining check balance.

GET /healthz

Global Anycast edge liveness probe. Returns HTTP 200 OK ({"status": "ok"}). No authentication required.

7. Errors & Rate Limit Behavior

Sentinel follows standard HTTP status conventions. Error payloads return structured JSON envelopes:

Status Error Code Trigger Condition Client Recommended Action
400 Bad Request INVALID_IP_FORMAT Supplied string is not valid IPv4 or IPv6 syntax. Validate IP format before querying API.
401 Unauthorized INVALID_LICENSE_KEY Authorization header is missing or key is corrupted. Check environment variable SENTINEL_API_KEY.
403 Forbidden QUOTA_DEPLETED Monthly check allotment has reached 0. Upgrade tier or wait for monthly cycle reset.
429 Rate Limited RATE_LIMIT_BURST Queries per second exceed burst threshold. Honor Retry-After header; apply exponential backoff.
500 / 503 Edge Error EDGE_ISOLATE_TIMEOUT Edge isolate timeout or temporary transit disruption. Fail-Open: Forward traffic to avoid downtime.
Resilience Pattern

8. Production Fail-Open Architecture

Security software should never create single points of failure. In production web applications and APIs, always wrap Sentinel calls in a fail-open handler: if network connectivity to the edge fails or times out, permit the connection and log a warning rather than locking out legitimate visitors.

javascript — Node / Express Fail-Open Middleware 
async function sentinelGuard(req, res, next) {
  const clientIP = req.headers["cf-connecting-ip"] || req.socket.remoteAddress;

  try {
    const controller = new AbortController();
    const timeout = setTimeout(() => controller.abort(), 1200); // 1.2s timeout

    const resp = await fetch(`https://api.antivpn.tech/v1/check?ip=${encodeURIComponent(clientIP)}`, {
      headers: { "Authorization": `Bearer ${process.env.SENTINEL_API_KEY}` },
      signal: controller.signal
    });
    clearTimeout(timeout);

    if (!resp.ok) return next(); // Fail-open on non-200

    const verdict = await resp.json();
    if (verdict.action === "BLOCK" && verdict.confidence >= 0.95) {
      return res.status(403).json({ error: "Access Denied: Untrusted Ingress" });
    }

    next();
  } catch (err) {
    // Fail-open: Never disrupt legitimate user traffic if edge network is unreachable
    console.warn(`[Sentinel Warning] Fail-open bypass for ${clientIP}: ${err.message}`);
    next();
  }
}
Implementation Pattern

9. Graduated Defense Policy Recipe

Take full advantage of confidence and reason_codes to separate deterministic datacenter/VPN drops from residential proxies:

javascript — Multi-Tier Graduated Enforcement 
function enforceIngressPolicy(verdict) {
  // 1. Deterministic Hard Drop (Commercial VPNs, Hosting Scrapers, Tor)
  if (verdict.risk_score >= 85 && verdict.confidence >= 0.95) {
    return { decision: "DENY", status: 403 };
  }

  // 2. Probabilistic Step-Up Challenge (Residential Proxies & Tunnels)
  if (verdict.reason_codes.includes("RESIDENTIAL_TUNNEL_PROXY")) {
    return { decision: "CHALLENGE", action: "PROMPT_CAPTCHA_OR_MFA" };
  }

  // 3. Clean Connection: Allow without friction
  return { decision: "PASS" };
}
