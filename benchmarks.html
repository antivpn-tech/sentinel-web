Epidemiological / Statistical Rigor

The base rate reality:
Why prevalence dictates real-world precision.

In an evaluation corpus with 69% threat traffic (18% residential proxies), the Positive Predictive Value (PPV) exceeds 99.6%. However, real-world gaming servers or web applications typically experience only 1% to 2% proxy prevalence. Bayes' theorem demonstrates how real-world precision responds to ingress base rates:

$\text{PPV} = \frac{\text{Sensitivity} \times p}{\text{Sensitivity} \times p + \text{FPR} \times (1 - p)}$  ·  (where $p = \text{proxy prevalence rate}$)

Why Mobile CGNAT (0.151% FPR) Dictates Graduated Defense

Behind Carrier-Grade NAT (CGNAT), thousands of distinct wireless subscribers share small egress IPv4 pools. At a 1% proxy prevalence, a 0.15% FPR yields a 86.8% PPV. If a server blindly drops connections on residential signals, innocent mobile players will be collateral damage. Sentinel provides continuous confidence floats and reason_codes so operators can prompt for 2FA or trigger rate-limits instead of issuing blind bans.

Latency Transparency

What "sub-millisecond"
honestly measures.

Network physics dictates that light in fiber travels ~200 km per millisecond. No global cloud API on Earth can offer a public internet round-trip (RTT) under 1ms. When vendors claim "sub-millisecond API", engineering teams deserve full clarity on where time is spent.

Local V8 Isolate Execution (<0.8ms)

Sentinel's <0.8ms evaluation specifically measures the local in-RAM radix trie computation once a request arrives at an edge node. The evaluation is stateless with zero database hops and zero disk writes.

End-to-End Application Transit (5ms – 25ms)

Total overhead equals your client-to-edge Anycast RTT (typically 5–25ms across 330+ locations) + the local isolate computation (<0.8ms). Sentinel adds virtually undetectable compute latency to unavoidable speed-of-light propagation.

SYSTEM ARCHITECTURE

Architecture decoupling:
Stateless edge vs. asynchronous decay.

How does Sentinel reconcile "stateless, zero-database edge compute" with "temporal correlation and automatic risk decay"? The two functions operate in strictly decoupled runtime planes:

Plane 1: Edge Ingress Isolate (Read-Only) 100% Stateless RAM Evaluation

Edge isolates operate with zero write-locks and zero database queries. Incoming packets are matched in volatile memory against a pre-compiled immutable Radix Trie and bitmask table. No request state or IP history is tracked inside the edge isolate.

Plane 2: Threat Grid Pipeline (Background) Asynchronous Temporal Correlation & Decay

Temporal decay functions, proxy churn tracking, and behavioral correlation run asynchronously in the Sentinel Threat Grid processing cluster. Every 5 minutes, the cluster compiles an updated snapshot delta and broadcasts it to edge isolate memory.
