Statistical Base-Rate Effect

Bayes' Theorem & Real-World Precision

In our 250,000 endpoint test corpus, proxy traffic prevalence is 18.0%. However, a typical Minecraft or game server observes only 0.5% to 2.0% proxy connection attempts. Under Bayes' theorem, Positive Predictive Value (PPV) depends heavily on real-world prevalence:

// Bayes' Theorem for Positive Predictive Value:
PPV = (TPR × p) / [ (TPR × p) + FPR × (1 - p) ]
TPR (Threat Recall) = 99.54%
FPR (Clean Control) = 0.079%

Why Mobile CGNAT (0.151% FPR) Demands Graduated Defense

Cellular carriers assign thousands of mobile subscribers behind a single egress IP via Carrier-Grade NAT (CGNAT). If a malicious actor on that cell tower routes proxy traffic, flagging that carrier IP can inadvertently impact real cellular players. This is why Sentinel provides granular confidence and reason_codes: developers can hard-kick datacenter proxies while issuing non-destructive authentication challenges (such as web authentication or Discord linking) for residential tunnel signals.

System Architecture Decoupling

Stateless Edge Execution vs. Background Threat Grid

A common technical question: how does Sentinel achieve "stateless, sub-millisecond edge evaluation" while maintaining "temporal correlation and risk decay"? The answer lies in strict pipeline separation:

1. Request Runtime Path < 0.8ms Compute

Zero-Log Volatile Memory Architecture

When an API request hits our Anycast edge, evaluation executes within a V8 isolate that accesses a compiled, immutable radix trie residing entirely in RAM.

  • ✓ Zero database queries during request evaluation
  • ✓ Zero disk writes or session persistence
  • ✓ In-RAM bitmask matching in < 0.8ms
2. Asynchronous Ingestion Path 5-Minute Sync Delta

Sentinel Global Threat Grid Pipeline

Temporal correlation, velocity anomaly detection, and risk decay execute asynchronously in our background Threat Grid aggregation cluster.

  • ✓ Dynamic tunnel churn tracked across time series graphs
  • ✓ Inactive proxy IPs decay exponentially over 12–72 hours
  • ✓ Compiled immutable delta broadcast every 5 minutes
