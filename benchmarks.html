Latency Transparency

What "Sub-ms" Honestly Measures

Network physics dictates that light in fiber travels ~200 km per millisecond. No global API can provide a public internet round-trip (RTT) under 1 millisecond.

Local Isolate Execution (<0.8ms)

When Sentinel states "sub-millisecond evaluation", it strictly measures the local in-memory V8 isolate compute duration once the request reaches the edge node. It executes an in-RAM radix trie lookup with zero database round-trips and zero disk persistence.

Total End-to-End Latency (5ms – 25ms)

Your application's real-world overhead equals: Client-to-Edge Anycast RTT (typically 5–25ms globally across 330+ locations) + Isolate Evaluation (<0.8ms). Sentinel adds negligible compute overhead to the unavoidable speed-of-light network transit.

Technical Reality

The Residential Proxy Reality: Why Nuance Matters

Commercial VPNs and cloud datacenters are easy to detect: they belong to fixed hosting ASNs and static IP prefixes. Residential proxies are fundamentally different.

Residential proxies operate through hijacked consumer endpoints, malware-infected home routers, or opt-in peer-to-peer bandwidth monetization software. The IP address belongs to a legitimate consumer ISP (e.g. Comcast, AT&T, Orange). At 10:00 AM, that IP might route a legitimate family watching television; at 10:05 AM, a covert tunnel may route a web scraper or credential-stuffing script.

Because of this dual-use reality, claiming "99.9% precision" across residential proxies is dishonest. Any vendor making that claim is either over-blocking innocent human users (creating severe false positives) or guessing.

Our Engineering Recommendation: Graduated Defense

Do not blindly hard-block IP addresses flagged with RESIDENTIAL_TUNNEL_PROXY if user conversion matters. Instead, inspect the confidence score and apply stepped-up friction: prompt for Multi-Factor Authentication (MFA), present a CAPTCHA, or restrict request velocity. Save hard drops (403 Forbidden) for deterministic commercial VPNs and cloud VPS hops.

Data Freshness & Proxy Churn Mitigation

Proxy IPs churn constantly. Threat lists downloaded as static daily files become dangerously stale within 48 to 72 hours, resulting in missed attacks and unjustified blocks on recycled IP blocks.

Continuous 5-Minute Ingress Deltas

Sentinel edge isolates do not pull daily batch dumps. The Sentinel Global Threat Grid streams continuous micro-delta updates into edge memory every 5 minutes worldwide.

Automated Temporal Decay

When a dynamic residential IP stops exhibiting anomaly proxy traffic, its risk score decays automatically. Legitimate broadband subscribers never suffer permanent IP blacklisting.

Response Freshness Headers

Every API response returns X-Sentinel-Dataset-Sync and X-Sentinel-Data-Age headers, allowing your microservices to verify telemetry freshness in real time.
