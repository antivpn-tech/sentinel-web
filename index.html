REST API Specifications

Global Serverless Edge Endpoints

Hosted across distributed serverless edge infrastructure at api.antivpn.tech with zero cold starts.

GET /v1/check?ip={target_ip}
Evaluates an explicit target IP address against proprietary threat intelligence and network routing classifications. Returns instantaneous verdict (ALLOW or BLOCK), risk_score (0-100), and threat categorization.
GET /v1/check
Automatically evaluates the calling client's connection origin using edge network telemetry. Ideal for browser connection inspection and client-side anti-fraud verification.
GET /healthz
Service health check endpoint for uptime monitors, load balancers, and heartbeat liveness probes. Returns status: "operational" with current timestamp.
